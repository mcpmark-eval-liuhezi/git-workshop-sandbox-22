# Exercise 1: Git Basics

This file introduces the core concepts of Git for the workshop.

## Learning Goals

- Understand what a repository is and how it differs from a remote.
- Learn basic commands: `git init`, `git clone`, `git add`, `git commit`, and `git status`.
- Practice making small, incremental commits so history stays easy to read.

## Exercise Steps

1. Clone the sandbox repository to your local machine.
2. Create a new branch for your own work.
3. Make a small change and commit it with a clear message.
4. Push the branch and open a pull request against `main`.
