# Exercise 2: Branching

This file covers branching workflows that you will use throughout the workshop.

## Learning Goals

- Learn how to create, switch to, and merge branches.
- Understand the difference between local and remote branches.
- Practice keeping feature branches focused and small.

## Key Concepts

- **Branching:** `git branch <name>` creates a pointer to your current commit; `git checkout <name>` (or `git switch`) moves you onto it.
- **Merging:** `git merge <branch>` brings changes from one branch into another.
- **Clean history:** Prefer one commit per logical change so `git log` stays easy to follow during demos.

## Exercise Steps

1. Create a branch called `student-exercises` (already done for you).
2. Add your exercise files on this branch.
3. Push the branch and open a pull request into `main`.
4. Review the commit history on the pull request to see how each commit appears.
